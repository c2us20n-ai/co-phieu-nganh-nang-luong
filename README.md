# Cổ Phiếu Ngành Năng Lượng

99 Thẻ Cổ phiếu ngành Năng lượng Việt Nam — Interactive cards.

## 🌐 Link web (sau khi bật Pages)

**https://c2us20n-ai.github.io/co-phieu-nganh-nang-luong/**

## Bật GitHub Pages (bắt buộc 1 lần)

1. Vào repo: https://github.com/c2us20n-ai/co-phieu-nganh-nang-luong
2. **Settings** → **Pages** (bên trái)
3. **Source**: Deploy from a branch
4. Branch: **main** · Folder: **/ (root)**
5. Bấm **Save**
6. Đợi 1–2 phút rồi mở link trên

## 📥 Đề xuất tải về

Khi mở web, banner phía trên có nút **Tải HTML** và **Tải hình nền**.

## Upload file còn thiếu (cards.html + hình nền)

Vì file HTML đầy đủ ~850KB và ảnh, bạn upload thêm qua web GitHub:

1. Vào repo → **Add file** → **Upload files**
2. Kéo thả:
   - `cards.html` (file 99 thẻ đầy đủ)
   - `Co-Phieu-Nganh-Nang-Luong.jpg` (hình nền)
3. Commit changes

Sau đó nút "Mở 99 thẻ" và hình nền sẽ hoạt động.
